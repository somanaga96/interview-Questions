### 1.**Smoke Testing**
Purpose: To check whether the major functionalities of the application are working properly after a new build is deployed.
### 2. **Sanity Testing**
Purpose: To validate that the new changes or bug fixes are working as expected and haven't broken related functionality.
### 3. **Regression Testing**
Purpose: To ensure that recent code changes (new features, bug fixes, updates) haven’t negatively impacted existing functionality.
