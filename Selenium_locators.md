
### 1) **Single slash vs double slash**
**A. Single slash**
 -**Absolute XPath**
 -**Fixed path from root**
 ```java
/html/body/div/input
```
**B. Double slash**
 -**Relative XPath**
 -**Searches anywhere**
 ```java
//input[@id='username']
```

### 2) **Id**
**A. Xpath**
```java
//*[@id="teamDropDown"]
```
**B. CssSelectors**
```java
div[id="teamDropDown"]
```
