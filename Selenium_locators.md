
### 1) **Single slash vs double slash**
**A. Single slash**
 -Absolute XPath
 -Fixed path from root
/html/body/div/input
**A. Double slash**
 -Relative XPath
 -Searches anywhere
//input[@id='username']

### 2) **Id**
**A. Xpath**
```java
//*[@id="teamDropDown"]
```
**B. CssSelectors**
```java
div[id="teamDropDown"]
```
